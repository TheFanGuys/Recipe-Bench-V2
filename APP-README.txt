THE RECIPE BENCH — GitHub Pages version

Upload EVERYTHING in this folder (index.html and the whole img folder, keeping the folder names) to the root of a GitHub repo, then turn on Pages (Settings > Pages > Deploy from branch > main / root).

Your link will be:  https://<your-github-name>.github.io/<repo-name>/

Works without a Claude account: all recipes, scaling, shopping list, saved recipes, Tools, Spice Rack, 3D home screen.
Not in this version (they need Claude): uploading cards/photos inside the app, automatic card titles, the duplicate-card check.
Saved recipes and shopping lists are stored on each phone separately.
To add new recipe cards: send them to Claude, then upload the new index.html and img files it gives you (replace the old ones).
